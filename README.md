# SQL Data Analytics Journey

Practical SQL study repository focused on Data Analytics,
business problems and technical interview preparation.

## Objective

Develop SQL skills through realistic business scenarios,
focusing on the reasoning expected from a Data Analyst.

## Database

The project uses a fictional company called DataCorp.

Main entities:

- Customers
- Orders
- Order Items
- Products
- Categories
- Employees
- Departments

## Topics

SQL Fundamentals
JOINs
Aggregations
GROUP BY
HAVING
Subqueries
CTEs
Window Functions
Ranking
LAG / LEAD
Data Analysis
Query Optimization
Data Modeling
